Getting started ​

Tilepress is a Windows app with PDF and image tools. It works on the files on your own PC: nothing is uploaded. This page covers installing it, the first launch, and the ways to get a file into a tool.

System requirements ​

  • Windows 10 or Windows 11, 64-bit. The installer is for x64 PCs.
  • The Microsoft Edge WebView2 Runtime. Tilepress draws its window with it. It comes with Windows 11 and with up-to-date Windows 10. On an older PC that doesn't have it, install the Evergreen WebView2 Runtime from Microsoft's WebView2 page.
  • A screen with room for the window. The window can't be made smaller than 980 × 600 pixels.
  • An internet connection only for a few things: the one-time LaTeX engine download, each AI model the first time you use its tool, and web pages you ask a tool to load. Everything else works offline. See Privacy for the full list.

Some tools use other software when it's there:

ToolUsesWithout it
Word to PDF, PowerPoint to PDF, Excel to PDFMicrosoft Office, or LibreOfficeThese three tools can't convert. Install either one, then restart Tilepress.

Install Tilepress ​

  1. Download the installer (.msi) from the Download page.
  2. Double-click it. On the welcome page click Next, then Install.
  3. On the last page, Launch Tilepress is ticked. Click Finish to start Tilepress.

The installer doesn't ask for administrator rights. It installs Tilepress for your Windows account only, in %LocalAppData%\Programs\Tilepress, and adds Tilepress to the Start menu.

Install for everyone on the PC ​

To install in Program Files for every user of the PC, open Command Prompt or Windows Terminal as administrator, go to the folder that holds the installer, and run:

msiexec /i Tilepress-x64.msi ALLUSERS=1

Use the name of the file you downloaded if it's different.

The first launch ​

Tilepress opens with three panels: the Explorer on the left, the tools in the middle, and the Preview on the right. The Explorer starts in your home folder. After that it reopens the last folder you were in. The Tilepress window explains every part.

The LaTeX engine downloads in the background ​

If no LaTeX engine is installed on your PC, Tilepress sets one up the first time it starts:

  1. It downloads Tectonic 0.15.0 (about 19 MB) and checks it against its known SHA-256 checksum. A file that doesn't match is thrown away.
  2. It compiles a small test document once, so Tectonic downloads the LaTeX packages most documents need (about 12 MB more).

This takes about two minutes and happens only once. The status bar at the bottom of the middle panel shows the progress: Downloading LaTeX engine…, then Installing LaTeX engine… and Fetching LaTeX packages…. You can use every other tool in the meantime.

If the setup fails, for example because you're offline, the status bar shows LaTeX setup failed. Click the status button in the top bar and choose Retry LaTeX setup, or just start Tilepress again later: it tries again on every start until the setup succeeds.

Nothing else is downloaded at start-up. The AI tools download their model the first time you use them, and tell you so first.

Open a file in a tool ​

First pick a tool. Choose Documents or Images at the left of the top bar, then a category tab, then the tool in the row underneath. Or press Ctrl+K, type part of the tool's name or what it does (for example merge, sign or word), and press Enter.

Then give the tool a file in any of these ways:

  • Select it in the Explorer. When the selected file suits the open tool, the tool shows a Use button with the file's name. Click it.
  • Drag it from the Explorer onto the tool. Dragging works from Tilepress's own Explorer pane; files dragged in from Windows File Explorer aren't picked up.
  • Right-click it in the Explorer and choose a tool from the menu (see the table below).
  • Use the buttons in the Preview pane. A PDF has PDF tools, an image has Edit photo, and a file that can be converted has Convert to PDF.
  • Use the tool's own button, such as Open PDF…, Open image…, Add PDFs… or Add images…, to pick a file in a Windows file dialog.

The right-click menu offers these tools:

Open in PDF tools opens the PDF in the page tool you used last (Organize PDF if that was Merge PDF). Convert from PDF opens it in the From PDF tool you used last.

One open PDF, one open image

The tools that work on a single PDF share it. Open a file in Split PDF, switch to Watermark PDF or Sign PDF, and the same file is already open. Merge PDF keeps its own list, and Protect PDF and Repair PDF keep their own file. In the same way, Crop Image, the AI tools and the Photo editor share one open image, while the batch image tools each keep their own list.

Every tool saves a new file and leaves the original alone. See The Tilepress window for the Saved card that appears afterwards.

Update Tilepress ​

Download the newer installer and run it. It replaces the installed version and keeps your pins, settings, history and downloaded models. Close Tilepress before you install the update.

An older installer won't install over a newer version. It stops with the message "A newer version of Tilepress is already installed."

Uninstall Tilepress ​

Open Settings > Apps > Installed apps, find Tilepress, and choose Uninstall. You can also run msiexec /x with the installer file.

Uninstalling removes the program but keeps your data in %LOCALAPPDATA%\Tilepress: settings, pins, history, the log, the LaTeX engine and the AI models. To remove those too, delete that folder after uninstalling. Tectonic keeps its downloaded LaTeX packages in %LOCALAPPDATA%\TectonicProject, which you can delete as well. Privacy lists what each item in the data folder is.

The tools ​

Documents:

  • Combine, split & pages: Merge PDF, Split PDF, Organize PDF, Rotate PDF, Crop PDF, Page numbers
  • Convert to PDF: Word, PowerPoint, Excel, images, HTML and Markdown to PDF
  • Convert from PDF: PDF to Word, PowerPoint, Excel, JPG and Markdown
  • Edit, forms & OCR: Edit PDF, OCR PDF, PDF Forms, Watermark PDF
  • Security, signing & size: Protect PDF, Sign PDF, Compress PDF, Repair PDF
  • Printing: Advanced Print
  • LaTeX: the LaTeX editor

Images:

  • Format & size: Compress Image, Resize Image, Convert to JPG, Convert from JPG
  • Crop, rotate, collage & capture: Crop Image, Rotate Image, Photo collage, HTML to Image
  • AI enhancements: Upscale Image, Remove background, Blur face
  • Edit & brand: Photo editor, Watermark Image
